# Unit Converter App

A simple unit converter Android application built using **Jetpack Compose**. This app allows users to convert values between different length units such as millimetres, centimetres, metres, and feet.

## ✨ Features

- 🔢 Real-time conversion as you type
- 📏 Convert between:
  - Millimetres
  - Centimeters
  - Metres
  - Feet
- 🧮 Instant result display
- 🎨 Modern UI with Jetpack Compose
